Usage

Use WASD to move the camera around.
Use Shift/Space to move the camera up/down.
Use ARROWS or left cursor to look around.
Press Home to look at the scene origin.
Press O to toggle mesh outlines.
Press L to set the scene light position.
Press F to toggle the font render test.
Use K/R/G/B to set the black/red/green/blue font positions.

Overview

sokol is a lightweight, cross-platform, single-header C/C++ framework that wraps modern 3D graphics APIs(OpenGL, D3D11, Metal, Vulkan) along with windowing and input into a simple, portable abstraction.

This project serves as a testbed for some of my most recent 3d-graphics related algorithms.
Some of the things I have worked on with it:
• OBJ file loading
• Blinn-Phong shading
• Solids of Revolution construction
• Cube mapping
• Custom font rendering pipeline
