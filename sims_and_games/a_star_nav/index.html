Usage

• Use the W/A/S/D keys to move the camera around.
• Use Shift/Space to move the camera up/down.
• Use the ARROWS to look around.
• Press F to set the from waypoint.
• Press T to set the to waypoint.
• Press TAB to swap the waypoints.
• Press ESCAPE to remove the waypoints.
• Press R to route a connection between the waypoints.
• Press L to set the scene light position.
• Press G to toggle the graph rendering.

Overview

This project is an experiment in using the A star graph traversal algorithm along a navigational mesh in 3d.

To do this, first the terrain mesh is loaded and scaled. Using a poisson-disc distribution, points are sampled across the xz plane. The height of the points are snapped to the terrain surface. Then, using delaunay-triangulation, a mesh of these waypoints is constructed. Then, an edge extraction finds all unique sets of edges within the waypoint triangulation. These waypoints and edges are sent into a graph struct.

Then the program routes a connection between the chosen from and to waypoints. This route is shown in the program with an animation scheme of particles linearly interpolated across the edges of the route.
