Usage

• Drag the left cursor across the image to show the target vs approximation.
• Reload the page to restart the process and choose a random image.

Overview

This project uses a hill-climbing algorithm to try and represent the given target image with a set of randomly placed, colored, and rotated shapes.

Each frame, a handful of randomly chosen shapes are stamped onto a guess image. For each shape, the difference between the target and guess is computed per pixel. If this total difference is lower than it previously was, that means this new shape better represents the image. That new shape is therefore kept and added to the approx image.

Motivation

After coming across the project primitive, I wanted to see if I could make something similar, but instead of just using one type of shape per representation, I combined triangles, rectangles, and ellipses into one.

This project could be used as a censoring algorithm. It could be modified to only run on a region of an image.
